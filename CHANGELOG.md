# Changelog

## 0.1.0

First public release of the benchmark artifact.

- Dataset identical to the paper (SHA-256 `c705eab4…`): 400 episodes from 40 seeds.
- `escalation-bench` command: `info`, `export`, `prompt`, `run`, `score`, `verify-data`.
- Dependency-free scorer that reproduces the paper's main-table values.
- Markdown audit reports with seed-bootstrap confidence intervals.
- Paper reproduction scripts in `reproduce/` and the five models' raw outputs in `results/`.
